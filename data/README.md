# Data and derived input files

This repository does **not** include the original benchmark or full derived dataset files. Obtain original data from their authorised sources, check applicable licenses and privacy constraints, and document any preprocessing needed for replication.

The following filenames are referenced by one or more uploaded notebooks (not all are needed for every experiment):

| Filename | Where it is used / origin |
|---|---|
| `qr_codes_29.pickle` | Original QR matrices from the baseline benchmark; used in baseline, corrected structural analysis, Exp6–Exp9 |
| `qr_codes_29_labels.pickle` | Labels corresponding to original QR array |
| `qr_full_feature_dataset_v2.csv` | Cleaned aligned QR–URL features; generated in the development notebook and reused across experiments |
| `FINAL_10feature_XGB_for_deployment.pkl` | Frozen 10-feature lexical classifier from development experiments |
| `phase14B_final_robust_features.json` | Feature list/configuration for the frozen lexical model |
| `esann_icann_psl_snapshot.txt` | Domain parsing/split audit reference for corrected Exp4/Exp9 (may use documented fallbacks) |
| `balanced_urls.csv` | Separate benign-versus-malicious URL dataset for external evaluation (not the same task as phishing-only QR testing) |
| `matched_holdout_predictions.csv` | Generated by Exp6; an input to Exp8 |
| `trad_style_raw_pixel_xgb_grouped.pkl` | Saved raw-pixel XGBoost from Exp6; Exp7/Exp8 may retrain when absent |
| `sample_level_robustness_results.csv` | Optional corrected Exp4 decoding cache for Exp7 |

**Important:** Many notebooks search for inputs in `Path.cwd()` or old Windows `C:\Users\LENOVO\...` paths. Move/reconfigure inputs locally before running and document which versions produced published results. Some pickle/model files can execute arbitrary code when loaded; use only trusted files.

**Security:** Do not commit credential files, local personal datasets, private third-party data or unreviewed URL-level output CSVs. A public repo may distribute harmful URL samples inadvertently. Ensure publication rights with the data owners.
